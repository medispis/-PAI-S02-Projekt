# Flota samochodowa — CRUD

Projekt szkolny: frontend w React do zarządzania flotą samochodową, uruchamiany przez Vite.

## Uruchomienie

```bash
npm install
npm run dev
```

## Budowanie

```bash
npm run build
```

## Funkcje

- Dodawanie, edycja i usuwanie samochodów.
- Wyszukiwanie po nazwie.
- Filtrowanie według rodzaju paliwa.
- Sortowanie po nazwie A–Z lub Z–A.
- Paginacja: 5 samochodów na stronę.

Dane są przechowywane w stanie React. Odświeżenie strony usuwa zmiany i przywraca dane początkowe.
